# 01 — 赛题与实验

> IAIC 算法主线的统一记录。官方数据开放前只验证接口、工程和代理链，不把假设写成赛事事实。

## 1. 赛题任务

官方已明确包含两类核心场景：

1. 高点视频中的水域漂浮物识别与告警；
2. 视频、遥感等多源数据中的河湖“四乱”、非法采砂和其他水面异常识别。

下列内容在官方数据开放前均为未知项：

- 文件格式、尺寸、波段和视频参数；
- 标签列表、层级和分布；
- 分类、检测、分割或变化检测的具体任务形式；
- 指定基座模型及调用方式；
- 评分指标和权重；
- JSON 字段和坐标规范；
- 决赛云端环境和资源限制。

## 2. 双链边界

```text
competition/
数据 → 模型 → 解析 → 后处理 → 评测 → JSON

唯一输出
DetectionResult
```

产品链不参与初赛评分主流程。

## 3. 数据开放前的三个 Spike

### Spike A｜遥感 Pipeline 与 Mock 提交链

```text
InputAdapter
→ Preprocessor
→ Tiler
→ ModelClient
→ Mosaic
→ ProductWriter
→ JSON Validator
```

目标：验证配置驱动、阶段可替换、结果可复现，不追求代理数据高分。

### Spike B｜遥感成果服务

```text
代理 GeoTIFF / 预测 GeoTIFF
→ COG
→ TiTiler
→ 最小地图浏览
```

目标：证明原始影像和预测产品能够被产品链消费。

### Spike C｜Mock 结果事件化

```text
DetectionResult
→ EvidenceBundle
→ AnomalyAlert
→ 人工确认 / 驳回
```

目标：验证“算法结果不直接成为治理事件”的核心边界。

## 4. 代理 Baseline

### 视频代理链

```text
公开漂浮物数据
→ 读取和预处理
→ 最小检测模型
→ 后处理
→ 评测
→ Bad Case
```

### 遥感代理链

```text
公开水域遥感数据
→ 读取与切片
→ 最小分类或分割模型
→ 拼接
→ 评测
→ Bad Case
```

代理数据只用于环境、接口和评测流程验证，不作为赛事指标。

## 5. 官方数据审计框架

2026-08-01 启用：

```text
下载与校验
→ 目录和格式审计
→ 标签与划分审计
→ 随机样本可视化
→ 数据质量与重复检查
→ 场景和长尾切片
→ 官方 DatasetAdapter
→ 第一份合法 JSON
```

数据审计结果和可宣称结论同步进入 `04_证据与风险台账.md`。

## 6. 实验记录

每轮实验至少记录：

- 实验编号；
- Git Commit；
- 数据版本；
- 配置文件；
- 模型与 Prompt 版本；
- 后处理参数；
- 指标与产物；
- Bad Case；
- 结论和下一步。

当前先使用 Git、配置文件和结构化实验记录。第一轮正式模型实验后再决定 MLflow；官方数据规则明确后再决定 DVC。

## 7. 阶段 Gate

### 数据开放前

- Pipeline 与 Mock JSON 可运行；
- COG + TiTiler 可运行；
- 人工核验最小链可运行。

### 数据开放后 24 小时

- 数据审计完成；
- 官方 Adapter 完成；
- 第一份合法 JSON；
- 第一轮平台评分。
