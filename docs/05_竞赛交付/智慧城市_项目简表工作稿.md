## （1）项目背景｜300 字以内

当前草稿：

河湖监管已经形成无人机、高点视频、卫星遥感和人工巡查协同的建设趋势，但真实项目往往由不同设备、算法厂商和存量平台共同组成。调研显示，人工核验、整改复核和销号闭环已经进入中央及地方采购，行业问题已不再只是“能否识别”，而是不同模型结果如何统一接入、不同来源证据如何组合、人工确认和处置结果如何形成可追踪数据，并持续反哺算法评测。山水智鉴面向这一集成与评测断点，构建可嵌入既有河湖治理平台的多模型适配、证据编排和人工核验能力。

## （2）立项思路｜300 字以内

当前草稿：

项目以 IAIC 水域异常识别赛为算法验证场，用官方数据和统一评测验证高点视频、遥感及指定基座模型的识别能力；再将标准化 DetectionResult 接入产品链，形成 EvidenceBundle、AnomalyAlert 和人工核验记录。项目不重复建设无人机硬件或完整河长制平台，而是通过开放 Schema、模块化模型适配、COG/TiTiler 遥感成果服务和 Replay/Eval 反馈机制，将算法能力嵌入既有核查、工单和城市治理系统。

## （3）解决方案｜600 字以内

```text
视频 / 遥感 / 指定基座模型 / 第三方算法
→ ModelAdapter
→ DetectionResult
→ EvidenceAssembler
→ EvidenceBundle
→ AlertEngine
→ AnomalyAlert
→ 人工确认或驳回
→ GovernanceEvent / 外部治理系统
→ 处置反馈
→ Replay / 模型 Eval
```

技术上采用算法链和产品链隔离：IAIC 链负责数据、推理、评测和 JSON；产品链负责证据核验、事件输出和反馈回流。遥感成果以 COG 为 V0 标准，通过 TiTiler 形成地图服务；后续根据数据规模引入 STAC、pgSTAC 和矢量服务。产品首先交付异常证据核验工作台，并通过 API 接入现有河长制、一网统管或第三方工单平台。

## （4）商业模式和预期效益｜300 字以内

面向水利、河湖管理、生态环境、景区水域运营单位及系统集成商，提供模型适配与评测、水域异常识别、人工核验工作台、既有平台 API 集成、专项数据治理和年度巡检服务。项目可按区域或河段私有部署，也可作为现有平台能力模块交付。预期通过统一接口降低重复集成成本，通过证据编排提高核验效率，并将确认、驳回和处置记录沉淀为模型迭代数据。具体效益等待官方数据实验和原型 UAT 验证。
