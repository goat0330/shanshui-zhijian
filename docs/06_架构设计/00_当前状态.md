## 三、架构总览

### 3.1 系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│  GEE 数据层                                                     │
│  S2 L2A (10m) | S1 GRD (10m dB) | DEM GLO30 (30m)             │
│  JRC GSW (30m) | ESA WorldCover (10m)                          │
└──────────────────────────┬──────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────────┐
│  遥感处理层 (pipeline/)                                         │
│  InputAdapter → Preprocessor(EPSG:4545, 10m) → FeatureExtractor │
│  → ModelClient(光学/SAR) → ChangeDetector → Fusion              │
│  → Polygonizer → ProductWriter                                  │
│  ├─ 光学分支: NDWI + 局部Otsu + JRC先验 + WorldCover过滤        │
│  └─ SAR分支: VH dB + Otsu + Lee滤波 + 双极化(可选)              │
└──────────────────────────┬──────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────────┐
│  产品服务层 (services/)                                         │
│  TiTiler (:8001) — COG 瓦片服务                                │
│  FastAPI (:8000) — 产品链 API + SQLite + 4 页面                │
└──────────────────────────┬──────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────────┐
│  前端页面 (services/templates/)                                 │
│  ├─ 水域地图 (NDWI/SAR/变化图层叠加 + 图斑)                     │
│  ├─ 核验工作台 (507条待核验 + 确认/驳回 + 结构化原因)           │
│  ├─ 事件与工单 (事件列表 + 工单创建/状态更新)                   │
│  └─ Replay 回放 (全流程时间线)                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 八层架构对照

参照 `03-架构设计/总体分层架构.md`：

| 架构层 | 完成度 | 说明 |
|--------|--------|------|
| L1 运行保障 | ⚠️ 部分 | 配置/日志有，无安全/许可证 |
| L2 接入适配 | ⚠️ 部分 | GeospatialAssetAdapter 有，视频/赛事无 |
| L3 数据与证据 | ✅ 基础 | COG + MANIFEST + HONESTY，无STAC/PostGIS |
| L4 数据处理 | ✅ | 重投影/配准/质量门禁/三态语义 |
| L5 感知工具 | ✅ | SAR + 光学双模 + 融合 |
| L6 事件智能 | ❌ | 无 Observation→Candidate→Event三级链 |
| L7 应用服务 | ⚠️ 骨架 | 有 API 但无 outbox/评测/状态机 |
| L8 体验层 | ⚠️ 骨架 | 4 页面，无证据时间线/评测实验室 |

## 六、关键决策记录

| ID | 决策 | 理由 |
|----|------|------|
| D-001 | 朝天门 4×4km AOI | 两江交汇含多种地物，验证 Pipeline 鲁棒性 |

## 八、启动方式

### 8.1 设置环境

```powershell
# PROJ 环境变量 (必须, 否则 rasterio 报错)
$env:PROJ_LIB = ".venv\Lib\site-packages\rasterio\proj_data"
```

### 8.2 运行 Pipeline

```powershell
cd 山水智鉴比赛
.venv\Scripts\python competition/spikes/chongqing_rs_demo/pipeline/run_pipeline.py
```

### 8.3 启动服务

```powershell
# 终端 1: TiTiler (COG 瓦片)
cd services
python titiler_config.py        # :8001

# 终端 2: FastAPI (产品链)
cd services
python main.py                  # :8000

# 导入 DetectionResults (启动后只需一次)
curl -X POST http://localhost:8000/api/v1/detections
```

### 8.4 访问页面

| 页面 | 地址 |
|------|------|
| 水域地图 | http://localhost:8000 |

| Replay 回放 | http://localhost:8000/replay |
| API 文档 | http://localhost:8000/docs |

## 十、已确认问题

| 问题 | 影响 | 状态 | 修复方案 |
|------|------|------|---------|
| PROJ_LIB 系统变量指向 PostGIS 旧版 | EPSG 代码无法解析 | 临时解决 | 启动前设置 `$env:PROJ_LIB` 或删除系统变量 |

| TiTiler 路由前缀 | TileJSON 返回 `/tiles/` 非 `/cog/tiles/` | 有变通 | 当前用静态 PNG 预览替代 |
| 前端为 Jinja2 模板 | 非正式前端 | 预期 | 架构已规划 React+MapLibre 迁移路线 |
| 缺人工验证集 | 水体检测精度未量化 | 待做 | 建议在 QGIS 标注 20-50 个样区 |
