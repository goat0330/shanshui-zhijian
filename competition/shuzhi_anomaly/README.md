# 赛题3 水域综合异常识别 — 线上审阅精简包

本目录是比赛数据集的**精简审阅版**，用于让 ChatGPT 等线上工具通过 GitHub 审阅数据概况，不包含完整图片数据。

## 数据背景

- 赛题：**水域综合异常识别**（6 分类图像分类任务）
- 来源：`水域综合异常识别_训练集+验证集/`（本机完整数据，约 **964MB**，未上传 GitHub）
- 数据集划分：`训练集`（1144 张，含 `train.json` 标签）+ `初赛测试集`（691 张，无标签）

## 审阅要点建议

1. **类别不均衡**：有漂浮物一家独大，其余 5 类合计仅 118 张。建议审阅重点放在如何处理小样本类别（数据增强、类别加权、重采样、少样本学习）。
2. **图像尺寸不一致**：`train.json` 中 width/height 从 640x853 到 4080x3060 不等（见 `data_manifest.json` 的 original_size），预处理需统一缩放。
3. **样本外观差异大**：部分图片为航拍/高视角，部分为低视角；有真彩色与疑似红外/增强色调。可检查 `samples/` 下图片确认。
4. **提交规范**：测试集预测输出为 `result.json`，格式与 `train.json` 一致（filename + label）。
