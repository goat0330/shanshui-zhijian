# IAIC 方案工作稿

> 当前为数据开放前 V0。所有指标和官方任务细节统一标记 TBD。

## 一、赛题理解

赛题面向高点视频和多源遥感中的水域异常识别，强调复杂环境、多源数据、边缘云协同和长尾类别。

当前已知：

- 包含漂浮物识别与告警；
- 包含河湖“四乱”、非法采砂等综合异常；
- 使用指定基座模型；
- 初赛输出标准 JSON；
- 晋级后需提交代码、方案和消融。

当前未知：

- 数据格式、标签和任务形式；
- 基座模型及调用限制；
- 评分指标和权重；
- JSON Schema；
- 决赛环境。

## 二、总体方案

```text
官方数据
→ DatasetAdapter
→ 指定模型 / 自研模型适配
→ DetectionResult
→ 确定性后处理
→ 本地评测
→ 标准 JSON
```

比赛评分链与产品链硬隔离。产品链只消费标准 DetectionResult。
