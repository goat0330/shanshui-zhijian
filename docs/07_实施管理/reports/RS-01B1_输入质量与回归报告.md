## 已知限制

1. **SarMetadata 推断**: 当前`from_asset_ref()` 使用合成元数据（orbit_direction=UNKNOWN, relative_orbit=-1）。真实元数据需要从 GEE 下载脚本或 S1 manifest XML 中提取。
2. **CRS 转换简化**: `_to_epsg4326` 使用 EPSG:45* 的固定缩放参数，非 108E 区域误差增大。
3. **默认 warn 策略**: 未设置 `validation_policy` 时默认 warn，不拒绝缺元数据的输入。比赛测评需要显式设置 strict。
4. **SpatialMetadata 注册时使用固定 transform_list** — 不同时相 image 的 transform 可能不同（当前简化处理）。

- 持续性门禁
- 对象排序
- S2 增强
- 视频和事件融合
