## 6. 干净室重构的遥感 Pipeline

参考 POS2IDON 的阶段思想，但独立设计接口：

```text
Acquisition / InputAdapter
→ Preprocessing
→ Tiling
→ Inference
→ Mosaic
→ Product Export
```

原则：

- 每层是独立类或协议；
- 配置显式传入；
- 不使用全局变量和 `import *`；
- 不在运行时自动克隆外部仓库；
- 模型、区域和输出产品可替换；
- 每层具有测试和可检查产物。


## 8. 实现前三个 Spike

### Spike 01｜Pipeline 与 Mock 提交链

验收：配置可替换、结果可复现、JSON 校验通过。

### Spike 02｜COG + TiTiler

验收：原始影像与预测图层可浏览、透明度可切换、异常区域可定位。

### Spike 03｜人工核验最小链

验收：DetectionResult 可聚合为 EvidenceBundle 和 AnomalyAlert，审核人可以确认或驳回并记录原因。

## 9. 源码与许可证边界

- 宽松许可证组件按许可证声明直接依赖；
- GPL/AGPL 项目只作行为和架构研究，不复制实现；
- 外部项目的代码、数据、权重和许可证分别审计；
- `references/02_开源仓库源码审计.md` 是详细审计事实源；
- 任何组件只有经过运行 Spike 后才加入 `pyproject.toml`。
