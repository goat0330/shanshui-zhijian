# 一、项目方案概述｜不超过 200 字

山水智鉴是一套可嵌入既有河湖监管平台的多模型适配、异常证据编排和人工核验中间件。系统将高点视频、遥感、赛事指定模型、自研模型及第三方算法统一转换为 DetectionResult，通过 EvidenceBundle 和 AnomalyAlert 形成可核验异常，并将确认、驳回、处置和复核结果沉淀为 Replay 与模型 Eval 数据。

# 三、项目产品（服务）化｜不超过 2000 字

## 1. 产品与服务特性

```text
模型适配与评测服务
水域异常 AI 识别服务
异常证据核验工作台
既有平台 API 集成
专项数据治理与模型迭代服务
```

产品不自建无人机、机巢和摄像头管理平台，而是通过标准接口消费其数据或模型结果。

## 2. 产品化实施计划

- POC：官方数据、代理数据和 Mock 业务链；
- Pilot：选择河段或水库，接入一种视频和一种遥感数据；
- 项目部署：与河长制、一网统管或第三方工单系统集成；
- 运营：模型监测、人工核验、Bad Case 和周期报告；
- 复制：通过 ModelAdapter、区域配置和责任路由复用。

# 四、市场与竞争｜不超过 2000 字

## 1. 市场概述

真实采购包含算法＋人工、视频识别、遥感核查、设备＋平台和年度巡检运营。主要客户包括水利、河湖管理、生态环境、景区水域和城市信息化单位。

## 2. 竞争优势假设

- 不绑定单一设备和模型；
- 以开放 Schema 接入既有平台；
- 多源证据和人工理由显式留痕；
- 同一反馈支持治理和模型两套评测；
- 可作为集成商的能力模块，而非要求整体替换。

以上均需通过 Spike、IAIC 实验和原型 UAT 验证。

## 3. 风险及应对

| 风险 | 应对 |
|---|---|
| 政府采购周期长 | 先面向集成商、运营单位和专项服务切入 |
| 现有平台功能重叠 | 以开放接口和模型治理定位集成 |
| 数据和隐私限制 | 私有部署、最小数据和权限审计 |
| 模型效果不稳定 | 人工核验、版本管理和回归评测 |
| 硬件适配复杂 | 建立 DataSource/ModelAdapter，不做硬件总包 |

# 五、商业模式｜不超过 2000 字

## 3. 获利方式

- 私有部署和平台集成费；
- 年度算法运维和升级服务；
- 专项遥感/视频巡检服务；
- 数据治理、样本标注和模型迭代服务。
