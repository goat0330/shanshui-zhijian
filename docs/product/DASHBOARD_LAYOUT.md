# 山水智鉴 — 驾驶舱 B2 布局方案

> 版本: v0.3 (B2 定稿)
> 更新: 2026-07-28
> 方案: B2 — 地图中心单屏布局（已确认）

---

## 布局原则

- 1920×1080 单屏全显示，**无页面级滚动**
- 信息密度从左上到右下递减（指标 → 空间 → 分析 → 明细）
- 不使用第三方图表库，全部用 CSS + SVG 实现
- 配色遵循 Design Tokens 系统，与研判工作台一致
- GovernanceMap 作为主视觉锚点居中

## 布局参数

| 区域 | 宽度 | 高度 | 内容 |
|------|------|------|------|
| Header | 全宽 1920px | 48px | 标题 + DataSourceBadge |
| KPI 行 | 全宽 | ~80px | 6 个态势卡片 6×1 |
| 左栏 | 280px | 剩余高度 | TrendChart + ReviewFunnel |
| 中间 | flex 1 | 剩余高度 | GovernanceMap |
| 右栏 | 300px | 剩余高度 | SpatialDistribution + TypicalCases |

## 组件说明

### GovernanceMap（中间主视觉）

- 复用现有 `GovernanceMap` 组件
- 加载 `candidates.geojson` 和 `events.geojson` 作为图层
- Candidate 按 change_type 着色，Event 按状态着色
- 支持缩放/平移/图层切换
- 禁用对比模式（简化操作）

### 顶部 KPI 行

- 6 张卡片单行排列，每张显示：图标 + 标签 + 数值
- 颜色编码顶部彩色边框
- 卡片值：异常候选 / 持久性异常 / 瞬态异常 / 待研判事件 / 已确认事件 / 监测范围

### 左栏（趋势 + 漏斗）

- **月度趋势**：4 个月柱状图，SVG 紧凑渲染
- **研判链漏斗**：4 阶段垂直排列（候选产生 → 证据就绪 → 已完成研判 → 已生成事件版本）
- 阶段间显示转化率

### 右栏（分布 + 案例）

- **类型分布**：水平柱状图，8 种变化类型按数量排序
- **典型案例**：5 张卡片显示标题、状态、变化类型、面积、日期、简述
- 卡片点击 → 跳转到 `/workbench?candidate_id=xxx`

## 数据源

| 数据 | 来源 | 加载方式 |
|------|------|----------|
| KPI + 趋势 + 分布 + 漏斗 + 案例 | `GET /api/v2/dashboard/snapshot` | 页面挂载时单次请求 |
| Candidate GeoJSON | `GET /api/v2/map/candidates.geojson` | GovernanceMap 内部加载 |
| Event GeoJSON | `GET /api/v2/map/events.geojson` | GovernanceMap 内部加载 |
