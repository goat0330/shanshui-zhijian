在Kaggle比赛中CNN预训练模型是最常见的技术，可以用于计算机视觉和语音类型的比赛。

其中**timm** (pytorch-image-models)是现在比较热门也支持模型比较多的库。

## timm介绍

timm 是包含众多图像模型、层、优化器、训练技巧、数据加载和数据扩增的库，可以很方便的用于ImagetNet数据集的训练与验证，可以很好的复现一些SOTA模型。

- image models
- layers
- utilities
- optimizers /s chedulers
- data-loaders / augmentations
- training / validation scripts

地址：https://github.com/rwightman/pytorch-image-models

文档：https://rwightman.github.io/pytorch-image-models/

## timm模型

timm支持了常见的CNN分类模型，也支持了最新的transromer分类模型：

- Big Transfer ResNetV2 (BiT)
- DeiT (Vision Transformer)
- Transformer-iN-Transformer (TNT)
- Vision Transformer

## timm数据扩增

timm也支持了比较新的数据扩增方法：

- Random Erasing
- Mixup
- CutMix
- AutoAugment
- AugMix w/ JSD loss
- Adaptive Gradient Clipping

## timm使用案例

加载模型和权重：

import timm
m = timm.create_model(
      'mobilenetv3_large_100', 
      pretrained=True)
m.eval()

提取图像特征：

import torch
import timm
m = timm.create_model('xception41', pretrained=True)
o = m(torch.randn(2, 3, 299, 299))
print(f'Original shape: {o.shape}')

o = m.forward_features(torch.randn(2, 3, 299, 299))
print(f'Unpooled shape: {o.shape}')

列举所有的预训练模型：

import timm
from pprint import pprint
model_names = timm.list_models(pretrained=True)
pprint(model_names)
