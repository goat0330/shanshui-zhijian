## 待验证内容

| 内容 | 验证方法 | 优先级 |
|------|---------|--------|
| 比赛测试集标签体系 | 官方数据开放 | P0 |
| 基座模型推理速度与精度 | API 或本地测试 | P0 |
| 时空去重规则有效性 | 代理数据 + 消融 | P1 |

## 禁止宣称内容

| 内容 | 理由 |
|------|------|
| "首次利用 AI 进行智能巡河" | 市场已有大量同类项目 |
| "准确率 99%" | 尚未拿到官方数据进行评测 |
| "覆盖 XX 类异常" | 标签体系待官方确认 |

## 数据使用边界

| 数据 | 使用限制 | 来源 |
|------|---------|------|
| 官方训练/测试集 | 仅用于比赛，不公开、不提交 Git | 比赛官网 |
| 代理训练数据 | 公开数据集，按要求引用 | CC/开放许可 |
| 市场采购信息 | 公开报道，用于产品方案 | 政府采购网/新闻报道 |

## 项目风险

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|---------|
| 官方数据格式与预期不符 | 中 | 高 | 代理数据覆盖多种格式 |
| 基座模型性能不足 | 低 | 中 | 预留多模型切换机制 |
| 竞赛时间冲突 | 中 | 低 | IAIC 优先，智慧城市方案复用 |
| 团队成员中途退出 | 低 | 高 | 文档化交接、模块独立开发 |
