# references/ — 调研与源码审计归档

本目录保存不进入主文档的大体量调研内容。主文档只引用结论，不重复维护全文。

| 文件 | 内容 | 当前结论 |
|---|---|---|
| `01_市场与采购项目审计.md` | 首批十个真实项目＋第二轮采购补证 | 市场闭环已成熟，机会转向开放接入、证据标准和反馈评测 |
| `02_开源仓库源码审计.md` | POS2IDON、eoAPI、Crisis Cleanup、FixMyStreet、OpenRemote | 组件复用和干净室重构，不 Fork 完整平台 |

## 使用规则

1. Agent 在提出产品或技术判断前先检索本目录；
2. 详细事实和来源保留在本目录；
3. 可宣称内容同步到 `docs/04_证据与风险台账.md`；
4. 冻结决策同步到 `docs/00_项目总纲.md`、`03_技术架构与开源底座.md` 和项目驾驶舱；
5. 不把“公开材料未说明”改写成“市场没有”。
