## 三种口径

| 口径 | 当前定位 | 是否属于初赛主模型 |
|---|---|---|
| 初赛算法 | 赛题3：1144张训练图的六分类单张图片识别，测试集695张 | 是 |

初赛分类任务不得默认读取平台、遥感和运行时目录；平台/遥感任务不得把初赛六分类误当成遥感分割任务。父目录只用于存放工作区，不作为默认开发入口。

## 事实优先级

数据目录中的实际可解码图片和官方 `train.json` 是数据事实源；本文件只说明项目边界，不能替代官方提交示例或线上评分规则。当前官方评测指标尚未确认，内部报告统一记录 Accuracy、Macro-F1、Balanced Accuracy、每类 Precision/Recall/F1 和 Confusion Matrix。
