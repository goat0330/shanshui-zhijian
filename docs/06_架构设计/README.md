# 06 — 架构设计

本目录保存架构师提供的当前状态和五份目标架构原文。阅读时必须区分“当前实现”和“目标设计”。

| 文件 | 作用 | 性质 |
|---|---|---|
| `00_当前状态.md` | develop 分支 V0 的实际完成情况 | 当前事实 |
| `01_总体分层架构.md` | 八层逻辑架构、职责和不变量 | 目标设计 |
| `02_领域模型与接口契约.md` | Observation、Candidate、Event、Prediction 等对象 | 目标契约 |
| `03_前后端工程框架.md` | 模块化单体、API、数据、前端、部署和 Gate | 目标工程框架 |
| `04_高点视频感知框架.md` | 固定高点视频完整链与最小纵切 | 目标设计 |
| `05_边云协同与数据流.md` | 边缘、云端、补传、降级和多源融合 | 目标设计 |

## 阅读顺序

1. 先读 `00_当前状态.md`，确认真实完成度；
2. 再读 `02_领域模型与接口契约.md`，理解对象边界；
3. 读 `01_总体分层架构.md` 和 `03_前后端工程框架.md`；
4. 视频成员读 `04`，部署成员读 `05`；
5. 实施任务进入 `docs/07_实施管理/`。

## 实施原则

- 不一次性重写当前代码；
- 先冻结最小契约；
- 用 Adapter 保持 DetectionResult 兼容；
- 先完成遥感验证和比赛链；
- 现有页面继续承担演示；
- 新架构以 Gate 和测试为完成定义。
