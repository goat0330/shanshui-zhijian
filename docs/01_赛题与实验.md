# 01 — 赛题与实验

> IAIC 算法主线的统一记录。数据开放前主要分析已知与未知，数据开放后持续追加评测结果、Bad Case 和消融结论。

## 赛题拆解

IAIC 水域异常智能识别赛道：

- **任务一：视频异常检测** — 高点视频（城市内涝/水域漂浮物/非法采砂/岸坡塌陷等）
  - 指定基座模型适配
  - 连续帧处理
  - 后处理与时空一致性
  - 评测方式：分类准确率 + 定位精度

- **任务二：遥感异常检测** — 卫星遥感图像（河湖四乱/水域变化/工程侵占等）
  - 遥感读取与切片
  - 多尺度分割或检测
  - 后处理与地理配准
  - 评测方式：分割精度 + 变化检测指标

## 已知与未知

| 方面 | 已知 | 待确认（官方数据开放后确认） |
|------|------|------------------------------|
| 数据格式 | 视频（MP4/H264）+ 遥感（高分多光谱） | 精确尺寸、标注格式（COCO/YOLO/语义掩码） |
| 标签体系 | 水域异常（漂浮物/四乱/水色/岸坡） | 标签列表、层级、标签分布 |

| 算力 | 自备 GPU 资源 | 显存限制、推理超时限制 |

## 代理数据实验

数据开放前至少完成两条代理链：

1. **视频漂浮物检测**：公开数据 → 预处理 → 检测 → 评测 → Bad Case
   - 模型：轻量检测器（YOLO 或 MMDetection）
   - 数据：公开漂浮物/XView 等水面检测数据集
   - 评测：mAP/Precision/Recall

2. **遥感水域分割**：公开数据 → 读取切片 → 分割 → 评测 → Bad Case
   - 模型：轻量分割（U-Net 或 MMSegmentation）
   - 数据：DeepGlobe Water/LoveDA 等公开遥感数据
   - 评测：IoU/F1
