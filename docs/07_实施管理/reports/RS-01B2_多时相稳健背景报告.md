# RS-01B-2 多时相稳健背景模型报告

## 1. 概述

### 1.1 用途

在 SAR 双时相变化检测（RS-01A/B-1）基础上，增加多时相稳健背景模型，
通过 6–24 景历史 Sentinel-1 GRD 影像构建像素级中位数背景，
对抗单景异常（辐射偏移、局部噪声）的干扰。

### 1.2 实现位置

| 组件 | 路径 | 说明 |
|------|------|------|
| 核心函数 | `tools/multi_temporal_background.py` | 纯 numpy 函数: median, MAD, valid_count, water_occurrence, zscore, classify |
| 工具集成 | `tools/sar_temporal_change_tool.py` | `_execute_multi_temporal()`, `_resolve_multi_temporal()`, `run()` 路由 |
| 测试 | `tests/test_rs01b2_multitemporal.py` | 18 个测试类，覆盖 14 类别 |
| 回归 | `scripts/run_regression_rs01b2.py` | 双时相回归 10498/510/769500 + 多时相真实数据 |

## 3. 参数配置

### 3.1 多时相策略（tool_config.multi_temporal）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `insufficient_history_policy` | `fallback_to_pair` | 历史不足时回退双时相，可选 `no_data` |
| `min_history_scenes` | 6 | 最小历史景数 (< 6 触发策略) |
| `max_history_scenes` | 24 | 最大历史景数 |
| `min_current_scenes` | 1 | 最小当前景数 |
| `max_current_scenes` | 3 | 最大当前景数 |
| `valid_count_threshold` | 3 | 低有效像元屏蔽阈值 |
| `mad_epsilon` | 0.001 | MAD 下限保护 (dB) |
| `zscore_threshold` | 3.0 | 鲁棒 Z-Score 阈值 |
| `water_occurrence_threshold` | 0.3 | 历史水体频率阈值 |
| `min_area_m2` | 500 | 最小图斑面积 (m²) |
| `pixel_area_m2` | 100 | 像素面积 (10m × 10m) |

### 3.2 Mode A 流程

```
1. INPUT: 12 history (VH+VV) + 1-3 current
2. EACH: read_geotiff → reproject_to_target(EPSG:4545)
3. ALL: resample_to_grid(first_history_grid)
4. vh_history_stack = [h0_vh, h1_vh, ..., hN_vh]  # (N, H, W)
5. compute_median_background → baseline_vh_median
6. compute_mad → baseline_vh_mad
7. compute_valid_count → history_valid_count
8. predict_vh(each_history) → water_history_stack → compute_water_occurrence
9. current stack → nanmedian → current_vh_median
10. predict_vh(current) → current_water_mask
11. compute_robust_zscore → robust_zscore
12. classify_multitemporal_change → 4 type masks
13. polygonize → GeoJSON + Observations
```

### 3.3 Mode B（双时相退化）

```
1. INPUT: before (T1) + after (T2)
2. 与 RS-01A.2 完全相同：predict_vh → detect_change → polygonize
3. 回归数据：10498 px / 510 polygons / 769500 m²
```

## 7. 已知限制

### 7.1 `_to_epsg4326` CRS 转换偏移

**问题**：`_to_epsg4326()` 函数使用硬编码近似转换 EPSG:4545 → EPSG:4326，
未考虑投影原点偏置（False Easting/Northing），导致 GeoJSON 坐标偏移
约 5° 经度、30° 纬度。

**影响**：candidates.geojson 的坐标在 111.24°E, 59.47°N 而非实际的
106.55°E, 29.55°N。

**来源**：RS-01A.2 遗留问题，双时相模式同样受影响。
回归数值（10498/510/769500）在输出空间内一致，但坐标精度不足。

**修复方向**：使用 rasterio.warp.transform() 或 GDAL 精确转换。

### 7.2 合成测试数据重投影

合成数据（16×16 EPSG:4326）经 `reproject_to_target` 后变为
413×406 EPSG:4545，水像素位置发生几何变化。IoU 测试因此使用
定性判定（变化类型存在且变化比率合理）而非严格 IoU 数值。

### 7.3 All-NaN 警告

重投影后部分边缘像素为 NaN，触发 `RuntimeWarning: All-NaN slice encountered`。
`compute_nanmedian` 和 `ensure_no_nan_inf` 安全处理了这些像素，
产物检验确认无 NaN/Inf 残留。

### 7.4 分类阈值（水增益/损失判定）

水增益/损失判定依赖 3 个超参数：`zscore_threshold` (3.0)、
`water_occurrence_threshold` (0.3)、`valid_count_threshold` (3)。
当前为经验值，未在不同地理区域上校准。

## 8. 双时相退化模式兼容性

当输入绑定仅有 `HISTORY + CURRENT` 角色且历史景数 < min_history_scenes：

| policy | 行为 |
|--------|------|
| `fallback_to_pair` | 内部抛出 `_FallbackToPair` 异常，`run()` 捕获后改走双时相 BEFORE/AFTER 流程 |
| `no_data` | 直接返回 FAILED（stage="history_check"） |

**注意**：`fallback_to_pair` 需要 `BEFORE + AFTER` 绑定可用，
若 NOT 配置则返回 INVALID_INPUT。
