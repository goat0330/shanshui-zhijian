## 2. 当前可宣称

- 水域 AI 监管的真实采购对象包含视频识别、遥感图斑、人工复核、整改复核、设备集成和运营服务；
- IAIC 高点视频和遥感任务具有直接市场需求；
- 成熟治理项目通常接入既有河长制或业务平台；
- 山水智鉴采用算法链与产品链隔离，并以 `DetectionResult` 作为唯一跨链接口；
- 山水智鉴将模型接入、证据编排和反馈评测设计为显式模块；
- POS2IDON、Crisis Cleanup 和 FixMyStreet 只作为思想与产品参考；
- V0 计划使用 COG + TiTiler 验证遥感成果服务。

## 4. 禁止宣称

- 首次利用 AI 智能巡河；
- 首次实现识别、人工核验、整改复核或销号；
- 现有平台都不支持模型替换；
- 现有平台都没有告警去重；
- 现有平台都没有模型反馈；
- 尚未实验却宣称准确率、效率提升或覆盖类别；
- 把代理数据结果写成 IAIC 官方数据结果；
- 把试点目标值写成稳定运营结果。

正确表达：

> 公开材料未充分说明该能力，山水智鉴将其设计为显式、标准化和可验证的产品模块。

## 5. 数据边界

| 数据 | 边界 |
|---|---|
| IAIC 官方数据 | 不公开、不提交 Git，遵守赛事授权 |
| 代理数据 | 只用于工程和 Baseline 验证，保留许可与引用 |
| 市场采购信息 | 支撑需求和商业判断，不替代用户访谈 |
| 合成事件 | 明确标记 Mock/Synthetic，不宣称真实业务成果 |
| 人工核验记录 | V0 使用演练角色，不宣称政府用户测试 |

## 7. 项目风险

| 风险 | 可能性 | 影响 | 缓解 |
|---|---:|---:|---|
| 官方数据形式与假设不符 | 高 | 高 | Adapter 和接口先行 |
| 指定模型受 API 限制 | 高 | 高 | 统一 ModelClient |
| 差异化被市场案例反证 | 中 | 高 | 聚焦开放接入和双评测 |
| 产品范围膨胀 | 高 | 高 | V0 只做到人工核验 |
| 组件审计后直接过度依赖 | 中 | 中 | 通过 Spike 后才入 pyproject |
| 两赛材料口径冲突 | 中 | 中 | 共享证据，区分验收 |
