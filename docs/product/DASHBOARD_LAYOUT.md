# 山水智鉴 — 驾驶舱 16:9 布局方案

> 版本: v0.2
> 更新: 2026-07-28
> 方案: A (推荐) / B

---

## 布局原则

- 黄金比例 16:9，目标分辨率 1920×1080，最低 1280×720
- 信息密度从左上到右下递减（态势 → 分析 → 明细）
- 不使用第三方图表库，全部用 CSS + SVG 实现
- 配色遵循 Design Tokens 系统，与研判工作台一致

---

## 方案 A：地图为中心（推荐）

### 布局示意

```
┌──────────────────────────────────────────────────────────────┐
│  Header: 研判驾驶舱                          [MOCK/DEMO]     │
├──────────────┬───────────────────────────────┬───────────────┤
│              │                               │               │
│  态势总览卡   │      空间分布柱状图            │   研判漏斗    │
│  6 张卡片     │      (CSS 水平柱状图)          │   4 阶段      │
│  2×3 网格    │                               │   垂直排列    │
│              │                               │               │
├──────────────┴───────────────────────────────┴───────────────┤
│                                                              │
│              时序趋势折线图 (SVG)                              │
│              Monthly Trend Line Chart                         │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│              典型案例卡片 (水平滚动)                            │
│              5 张卡片 / 3 列可见                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 说明

- **顶部行**: 6 张态势卡片（2×3 网格），颜色编码顶部边框
- **中间上**: 三栏布局 — 左(空间分布柱状图) 中(无) 右(研判漏斗)
- **中间下**: 时序趋势 SVG 折线图，全宽显示，突出时间维度变化
- **底部**: 典型案例水平滚动卡片，支持点击跳转工作台

### 优点
- 信息密度高，16:9 大屏利用率好
- 趋势图全宽，突出时间维度
- 空间分布 + 漏斗左右对照，因果逻辑清晰

### 缺点
- 没有嵌入地图，缺少空间定位感
- 底部卡片区域在大屏上可能显得内容不足

## 方案 B：地图 + 分析（带 Map 区域）

### 布局示意

```
┌──────────────────────────────────────────────────────────────┐
│  Header: 研判驾驶舱                          [MOCK/DEMO]     │
├────────────────────┬──────────────────┬─────────────────────┤
│                    │                  │                     │
│   态势总览卡        │   态势总览卡      │   态势总览卡         │
│   前 3 张          │   后 3 张        │   研判漏斗          │
│                    │                  │   4 阶段            │
│                    │                  │                     │
├────────────────────┴──────────────────┴─────────────────────┤
│                                                              │
│              地图区域 (GovernanceMap 复用)                     │
│              -  显示全部 Candidate 热点                        │
│              -  按 change_type 彩色渲染                        │
│              -  与工作台共享 MapLibre 实例                      │
│              -  简化交互（禁选、禁对比、只缩放/平移）            │
│                                                              │
├────────────────────┬────────────────────────────────────────┤
│   时序趋势图        │   空间分布柱状图                           │
│   (SVG 折线/柱状)  │   (CSS 水平柱状)                          │
│                    │                                          │
├────────────────────┴────────────────────────────────────────┤
│                                                              │
│              典型案例卡片 (水平滚动)                            │
│              5 张卡片 / 3 列可见                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 说明

- **顶部行**: 三栏 — 态势卡前3张 | 态势卡后3张 | 研判漏斗
- **中间上**: 全宽地图区域，复用 `GovernanceMap` 组件
  - 参数 `readonly: true` — 禁选、禁对比模式、禁图层编辑
  - 默认加载 Candidate 和 Event GeoJSON 图层
  - 不可进行候选选择/对比操作，仅用于空间态势感知
- **中间下**: 两栏 — 左(时序趋势) + 右(空间分布)
- **底部**: 典型案例水平滚动卡片

### 优点
- 地图直观展示空间热点，与工作台体验一致
- 信息完整：空间→时间→类别→明细
- 组件复用率高，开发成本低

### 缺点
- 地图区域挤占分析图表空间，需要滚动查看完整内容
- 地图渲染成本高（MapLibre 实例开销）
- 16:9 大屏下底部内容可能折行

## 决策建议

**推荐方案 A** 用于：
- 比赛演示场景（评委在 16:9 屏幕上观看）
- 汇报展示（信息一目了然，无需地图交互）
- 首版 MVP（实施简单、不依赖 MapLibre 大屏适配）

**方案 B** 用于：
- 管理者日常监控（需要空间定位）
- 大屏长期部署（地图作为主视觉锚点）

### 实施优先级

```
P0 ─ 方案 A 布局 + 全部 5 个组件 + Mock 数据
P1 ─ 典型交互（案例跳转工作台、刷新）
P2 ─ 方案 B（如有需要）
P3 ─ 真实 API 接入
```
