# 02 — 产品与业务方案

> 把算法结果转成真实治理业务。前期相当于 Product Brief，后期逐步成长为 PRD。

## 用户与角色

| 角色 | 职责 | 核心需求 |
|------|------|---------|
| 河道巡查员 | 现场核验告警、拍照反馈 | 任务列表、导航到现场、快速拍照记录 |
| 河湖监管负责人 | 接收告警、下发工单、跟踪处置 | 管辖范围概览、告警研判、处置闭环 |
| 水务管理者 | 看整体态势、关注趋势和风险 | 区域态势、问题发现率、处置时长统计 |

## 业务链

```text
DetectionResult         — 模型识别输出（类型、位置、置信度、帧/切片）
    ↓
EvidenceBundle          — 连续帧/多源证据聚合（时空关联去重）
    ↓
AnomalyAlert            — 持续性验证 + 风险规则触发 → 待核验告警
    ↓
人工核验                — AI 建议 → 人工确认/驳回 + 原因记录
    ↓
GovernanceEvent         — 确认为真实问题的事件（首次出现时间、空间、证据链）
    ↓
WorkOrder               — 治理工单（处置部门、时限、要求）
    ↓
现场反馈                — 整改照片、IVR 核实、处置完成
    ↓
Replay / 复盘            — 全链路回放 + 模型评测反馈
```

## 人机边界

| 步骤 | AI 自主 | 人工审核 | 备注 |
|------|---------|---------|------|
| 模型推理 | ✓ | - | 自动运行 |
| 证据聚合去重 | ✓ | - | 规则驱动 |
| 持续性验证 | ✓ | - | 告警阈值可调 |
| 告警确认 | 建议 | ✓ | 强制人工 |
| 治理事件 | 自动生成 | ✓ | 人工可修改 |
| 工单下发 | 预填 | ✓ | 人工审批 |
| 处置完成 | - | ✓ | 需反馈证据 |

## MVP 产品范围

- 水域异常检测结果可视化
- 告警生成与人工核验
- 治理事件记录与跟踪
- 处置反馈与基础统计
- 页面：地图概览、告警列表、事件详情、工单管理

**暂不纳入 MVP**：复杂工作流、多 Agent 编排、预测模型、社会影响模拟。

## 产品页面

1. **态势总览**（地图 + 关键指标卡片）
   - 今日告警数、待核验、处置中、已完成
   - 区域热力图
2. **告警列表**（按时间/严重程度/类型排序）
   - 一键跳转核验
   - 批量驳回/确认
3. **事件详情**（Evidence → Alert → Event 时间线）
   - 原视频帧/遥感切片
   - 模型判断与置信度
   - 人工核验记录
4. **工单管理**（待处置、进行中、已完成）
   - 现场反馈照片对比
