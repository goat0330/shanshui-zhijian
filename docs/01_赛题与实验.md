# 01 — 赛题与实验

> 记录赛题假设、数据审计、Baseline、指标、实验和官方数据切换。任何候选数量不得替代精度指标。

## 1. 当前遥感 V0

研究区域：重庆朝天门两江交汇，约 4×4 km。  
目标坐标系：EPSG:4545。  
统一分辨率：10 m。

当前链路：

```text
GEE
→ S1/S2/DEM/JRC/WorldCover
→ 地理配准与质量检查
→ S1 双时相水体掩膜
→ 变化图斑
→ 面积过滤
→ DetectionResult 兼容输出
→ 产品核验
```

已产生 507 条变化候选。该数字只说明 Pipeline 能够产出图斑，不说明 507 条均为真实水域异常。

## 2. 当前最关键的实验问题

当前不是“换哪个深度学习模型”，而是先回答：

1. 水体掩膜是否正确；
2. 双时相变化是否主要来自真实变化还是水位、噪声和几何误差；
3. 山区 layover、shadow 和坡度是否造成系统性误检；
4. 固定 500 m² 阈值是否适合所有河段；
5. S1 的 VV、VH、VV/VH 和时序统计哪个更稳定；
6. S2 在多云条件下能否作为证据，而不是主检测链；
7. 候选如何分级，减少人工审核负担；
8. 官方任务与当前“水面变化”代理任务有多大差异。

## 4. 验证集 V0

### 4.1 最小规模

先标注 20—50 个样区，不追求大而全。样区必须覆盖：

- 稳定水面；
- 稳定非水面；
- 岸线变化；
- 桥梁与码头；
- 船只与尾迹；
- 山体阴影；
- 城市建筑强散射；
- 浑浊水与低风水面；
- 云、云影和无数据；
- 疑似真实变化。

### 4.2 标注层级

至少形成三类真值：

1. `water_mask_truth`：水体/非水体；
2. `change_truth`：变化/无变化/不确定；
3. `candidate_review`：有效候选/误报/无法判断及原因。

### 4.3 指标

水体分割：

- Precision；
- Recall；
- F1；
- IoU；
- 按场景切片指标。

变化候选：

- 区域级 Precision/Recall；
- 面积加权 IoU；
- 候选级命中率；
- 每平方公里误报数；
- 人工审核前 N 条的有效率。

若官方任务为检测、分割或分类，应替换为官方指标，但保留当前代理指标用于回归测试。

## 5. 遥感 Baseline 梯度

### R0｜可复现基线

- 固定 AOI、时段、轨道和配置；
- 同一输入重复运行输出稳定；
- 生成 Run Manifest；
- 建立最小单元和集成测试。

### R1｜人工验证基线

- 完成验证集；
- 输出总体和切片指标；
- 建立 Bad Case 图册；
- 将 507 条候选按质量和置信分层。

### R2｜S1 预处理与质量门禁

实验项：

- 同轨道、同相对轨道与相近入射角；
- 轨道文件、热噪声和边缘噪声处理；
- 斑点滤波 A/B；
- DEM 坡度过滤；
- layover/shadow 质量掩膜；
- VV、VH、VV/VH、VV−VH 特征；
- 分河段局部阈值与全局阈值对比。

每项只保留能在验证集上稳定提升的配置。

### R3｜多时相稳健变化

将 T1/T2 改为：

```text
历史多景基线
→ 中位数/分位数与离散度
→ 当前时段合成
→ 稳健变化分数
```

优先测试：

- 3—6 个时段；
- median + IQR；
- 持续出现次数；
- 连续两期确认；
- 水位变化和季节岸线的抑制。

### R4｜S1 主检测 + S2 证据

S2 不强制承担主链，而用于：

- SCL/云影质量；
- NDWI、MNDWI、AWEI；
- 岸线和地物解释；
- 候选证据快照；
- 在晴空样区对 S1 结果做交叉核验。

### R5｜对象级候选优化

对图斑增加：

- 面积、周长、紧致度；
- 与稳定水体的连通性；
- 与历史岸线距离；
- 桥梁、码头、建筑和坡地排除；
- 图斑合并、孔洞填充和简化；
- `confidence`、`quality`、`severity` 分离；
- Top-N 候选排序。

### R6｜官方任务适配

官方数据开放后只替换：

- CompetitionInputAdapter；
- 标签映射；
- 模型或规则配置；
- PredictionRecord Exporter；
- Submission Validator。

产品 Event、Review 和 WorkOrder 不参与官方提交。

## 6. 实验矩阵

| 实验组 | 自变量 | 固定项 | 主要指标 |
|---|---|---|---|
| E-S1-01 | VV / VH / 比值 / 差值 | AOI、时段、滤波 | 水体 IoU、候选 Precision |
| E-S1-02 | 全局/局部阈值 | 特征、样区 | 切片稳定性 |
| E-S1-03 | 不同斑点滤波 | 特征、阈值 | 边界与误报 |
| E-QA-01 | 坡度、阴影质量门禁 | 模型 | 山区误报 |
| E-TIME-01 | 双时相/多时相 | 特征、AOI | 变化 Precision |
| E-FUSION-01 | S1 only / S1+S2 证据 | S1 主链 | 人工审核有效率 |
| E-OBJ-01 | 图斑规则 | 像元输出 | 候选级指标 |

一次实验只改变一组主要变量。

## 7. COG 与地图验收

完成定义：

```text
GeoTIFF
→ 合法 COG
→ TiTiler /tilejson.json
→ MapLibre raster source
→ 原始影像与结果图层
→ 透明度切换
→ 点击矢量候选
```

必须验证：

- COG 内部瓦片和 overviews；
- CRS、bounds 和 nodata；
- TileJSON 中 URL 前缀正确；
- 浏览器请求不依赖本地绝对路径；
- 静态 PNG 只作调试，不算正式完成。

## 8. 官方数据开放后的 24/72 小时

### 0—4 小时

- 文件清单、大小、许可、波段、CRS、时间；
- 标签和样本 ID；
- 官方指标；
- 推理资源和网络限制；
- 提交 Schema。

### 4—12 小时

- 最小 Adapter；
- 一条样本端到端；
- 空结果与失败语义；
- 第一份 PredictionRecord。

### 12—24 小时

- 全量最小推理；
- SubmissionBundle；
- Validator；
- 首次提交；
- Baseline Report V1。

### 24—72 小时

- 错误分层；
- 训练/验证泄漏检查；
- 任务切片；
- 只启动有证据的 A/B；
- 固化可复现环境。

## 9. 禁止事项

- 在没有验证集时用候选数量证明效果；
- 将水位变化直接写成污染或违法异常；
- 混用不同轨道、极化或未配准影像；
- 以普通 resize 代替地理重投影；
- 用产品人工审核结果修改比赛 PredictionRecord；
- 同时更换数据、特征、模型和后处理后宣称某一项有效；
- 在官方数据发布前锁死最终模型框架。
