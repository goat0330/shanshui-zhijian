# 山水智鉴 — 智慧水域监管智能体

覆盖 IAIC（水域异常智能识别赛道）和智慧城市技术与创意设计大赛的赛研一体化项目。核心定位：构建从任意模型识别结果到可核验治理事件的开放中间层，让 AI 识别能力真正进入水环境治理业务闭环。

## 两条主线

| 主线 | 目标 | 当前阶段 |
|------|------|----------|
| **competition/** | IAIC 算法链：数据 → 模型 → 评测 → JSON 提交 | 代理数据 Baseline |
| **docs/** | 产品与竞赛材料：方案、说明书、商业计划书 | 持续维护 |
