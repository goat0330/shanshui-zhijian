# 产品方案｜多源水域治理中间件

## 产品定位

山水智鉴是可嵌入既有河湖监管平台的多模型适配、证据编排与反馈评测中间件。产品方案保留多源输入，但不把某一个比赛模型等同于完整治理平台。

```text
图片 / 高点视频 / 无人机 / 遥感
→ ModelAdapter
→ DetectionResult
→ EvidenceBundle
→ AnomalyAlert
→ 人工确认 / 驳回
→ GovernanceEvent 或外部平台
```

## 三种输入能力

| 输入 | 产品用途 | 当前工程归属 |
|---|---|---|
| 现场图片、监控截图 | 六分类初赛模型、图片核验 | 独立初赛算法仓库 |
| 高点视频、无人机 | 多帧证据、巡查和现场复核 | 产品/视频支线 |
| 遥感影像 | 水体范围、岸线和多时相变化 | 山水智鉴遥感支线 |

初赛六分类模型可以通过 Adapter 接入产品，但产品代码、人工核验状态和遥感结果不得反向改变初赛预测记录。

## 人机边界

- 模型负责产生预测和证据候选，不直接形成治理结论；
- 系统负责证据聚合、重复候选整理和告警草稿；
- 人工负责确认、驳回、责任主体和工单下发；
- 反馈结果进入 Bad Case 和 Eval 数据集，用于后续模型迭代。

## 当前最小范围

先稳定 `DetectionResult → EvidenceBundle → AnomalyAlert → 人工确认/驳回`。完整工单、责任路由和多源融合属于产品后续能力，不作为初赛分类训练前置依赖。
